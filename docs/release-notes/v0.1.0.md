# PlainEssay v0.1.0

首个 macOS 版本：一个安静的本地写作应用。

## 功能

- 文档库：按最近编辑排序、字数、本地时间、空状态、删除确认
- 编辑页：标题 + 正文、B/I/U、字数、`Saving… / Saved` 自动保存
- 本地 SQLite 存储，无账号、无云同步、无遥测
- 导出 Markdown（合法 CommonMark，下划线保留为 `<u>`）
- 导出 Word（Times New Roman 12pt、双倍行距、1 英寸页边距、粗体/斜体/下划线）
- 原生 macOS 菜单与快捷键、overlay 标题栏、窗口状态恢复
- 响应式布局，为后续 iOS/Android 预留

## 安装

1. 下载 `PlainEssay_0.1.0_universal.dmg`（Apple Silicon + Intel，macOS 12+）。
2. 打开 DMG，将 PlainEssay 拖入 `/Applications`。
3. 右键应用 → 打开 → 打开。未签名/未公证，首次启动需要手动放行。
4. 若提示已损坏，执行：

```sh
xattr -dr com.apple.quarantine /Applications/PlainEssay.app
```

## 数据位置

```text
~/Library/Application Support/com.phanstal.plainessay/plainessay.db
```

删除应用不会删除数据；如需清空，请手动删除上述目录。

## 已知限制

- 无代码签名与公证，无自动更新
- 仅段落 + 粗体/斜体/下划线
- 删除不可撤销
- 窗口关闭时最多丢失最后约 600 ms 的输入（返回或 `⌘S` 会立即保存）
- 无数据库加密、无同步、仅英文界面

## 校验

```sh
shasum -a 256 -c PlainEssay_0.1.0_universal.dmg.sha256
```
