# Plain v0.1.8

对齐 **Figma Make Version 27**（4:33 PM「Support multiline essay titles」）。本次同时落地 Version 25–27 的三处行为变化；设计静态稿只用于确认版本，所有界面与交互以 Make 为准。

## 多行标题

- 标题输入由单行 `<input>` 改为 `rows=1` 的 `<textarea>`，最多 160 个字符。
- 标题随内容自动增高：输入换行时高度按 `scrollHeight` 更新，不再出现内部滚动条。
- 单行标题仍保持 39px 高、33.12px / 1.18 的排版；移动端 28px / 33.04px。
- 文档库行与顶栏仍按单行省略显示，不改变列表行高。

## 打开文档时光标位置

- 新建文档：光标仍落在正文开头。
- 打开已有文档：光标落在正文末尾（Version 26）。
- 统一由 `autoFocus: 'start' | 'end'` 控制，文字与选中行为不变。

## Word 导出

- Typeface 恢复可选：`Times New Roman · 12 pt` / `Arial · 12 pt`。
- Line spacing 恢复可选：`Double-spaced` / `Single-spaced`。
- Paper size 保持可选：`US Letter · 8.5 × 11 in` / `A4 · 210 × 297 mm`。
- 首次点击 `Export .docx` 会先显示 **Review in Word before submitting** 提醒：
  - 提示 Microsoft Word 渲染与作业要求可能存在差异，建议提交前在 Word 中检查。
  - 提供 `Don’t remind me again`；勾选并确认后写入 `localStorage["plain-hide-export-notice"]="1"`，之后不再提示。
  - `Go back` 返回导出设置；`Confirm & export` 执行导出。
- DOCX 生成按所选字体、行距和纸张尺寸输出；标题居中，1 英寸页边距、0.5 英寸首行缩进、黑色文字，保留粗体/斜体/下划线与图片。

## 其它

- 设计基线更新为 `docs/design/prototype-v27.css` 与 Version 27 参考图。
- 补充 Version 27 的导出提醒、移动端与版本历史截图。

## 安装

1. 下载 `Plain_0.1.8_universal.dmg`（Apple Silicon + Intel，macOS 12+）。
2. 打开 DMG，将 `Plain` 拖入 `/Applications`。
3. 右键应用 → 打开 → 打开。未签名/未公证，首次启动需要手动放行。
4. 若提示已损坏，执行：

```sh
xattr -dr com.apple.quarantine /Applications/Plain.app
```

## 数据位置

```text
~/Library/Application Support/com.phanstal.plainessay/plainessay.db
```

删除应用不会删除数据；如需清空，请手动删除上述目录。

## 已知限制

- 无代码签名与公证，无自动更新
- 仅段落 + 粗体/斜体/下划线 + 本地图片；不支持标题层级、列表、链接、图片缩放/裁切
- 单张图片上限 12 MB；WebP 可显示和导出 Markdown，但 Word 导出会跳过
- 查找替换按单个文本节点匹配，跨格式边界的短语不视为一个匹配
- 删除不可撤销
- 窗口关闭时最多丢失最后约 700 ms 的输入（返回或 `⌘S` 会立即保存）
- 无数据库加密、无同步、仅英文界面
