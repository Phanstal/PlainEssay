# Plain v0.1.7

把桌面端可见 UI、状态与交互统一到 **Figma Make Version 24**（2026-11-09 10:56 AM「Remove document count」）。设计静态稿只作为布局基线，所有界面行为以 Make 为准。

## 文档库

- 移除顶部导航、Plain 字标和文档总数。
- 标题区、`New essay ＋` 按钮、列表行、字数与时间排版按 Version 24 重新对齐。
- 行操作（铅笔 / 垃圾桶）改为 hover 或键盘聚焦时才显示。
- 删除使用系统原生确认框：`Delete “标题”? This action cannot be undone.`
- 空库显示 `Start a new essay` 虚线卡片。

## 编辑页

- 顶栏左侧显示当前文档标题，不再显示 Plain 字标；没有标题时回退为 `Untitled Essay`。
- 移除标题下方分隔线。
- 新建文档默认标题为 `Untitled Essay`，光标自动落在正文开头。
- 撤销 / 重做改用 Version 24 的 SVG 图标，不再显示禁用状态；粗体 / 斜体 / 下划线不再显示 active 状态，与 Make 一致。
- 自动保存防抖调整为 700 ms；保存状态文案与圆点状态同步 Make，失败时显示 `Couldn’t save`。

## Word 导出

- 打开 `Export document` 弹窗时，Typeface 固定为 `Times New Roman · 12 pt` 且禁用，Line spacing 固定为 `Double-spaced` 且禁用。
- Paper size 仍可在 `US Letter · 8.5 × 11 in` 与 `A4 · 210 × 297 mm` 之间选择。
- 导出按钮文案固定为 `Export .docx`。
- 保留 1 英寸页边距、0.5 英寸首行缩进、黑色文字、弯引号转换和图片导出。

## 其它

- 桌面端 1440×900 与移动端 390×844 的字体、间距、圆角、阴影和聚焦状态按 Make 逐项核对。
- 更新设计基线、Version 24 参考图和实现截图。
- 版本号升至 `0.1.7`；图标与 v0.1.6 相同。

## 安装

1. 下载 `Plain_0.1.7_universal.dmg`（Apple Silicon + Intel，macOS 12+）。
2. 打开 DMG，将 `Plain` 拖入 `/Applications`。
3. 右键应用 → 打开 → 打开。未签名/未公证，首次启动需要手动放行。
4. 若提示已损坏，执行：

```sh
xattr -dr com.apple.quarantine /Applications/Plain.app
```

## 数据位置

```text
~/Library/Application Support/com.phanstal.plainessay/plainessay.db
```

删除应用不会删除数据；如需清空，请手动删除上述目录。

## 已知限制

- 无代码签名与公证，无自动更新
- 仅段落 + 粗体/斜体/下划线 + 本地图片；不支持标题层级、列表、链接、图片缩放/裁切
- 单张图片上限 12 MB；WebP 可显示和导出 Markdown，但 Word 导出会跳过
- 查找替换按单个文本节点匹配，跨格式边界的短语不视为一个匹配
- 删除不可撤销
- 窗口关闭时最多丢失最后约 700 ms 的输入（返回或 `⌘S` 会立即保存）
- 无数据库加密、无同步、仅英文界面
