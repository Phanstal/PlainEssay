# PlainEssay v0.1.5

同步 Figma Make Version 12 的最终视觉微调。

## 界面

- 左上角字标从 `plainessay` 改为 `Plain`，文档库、编辑页和加载/错误状态保持一致。
- 重新生成应用图标：淡蓝圆角纸面、蓝色横线、右上角加号；同步替换 macOS `icns`、Windows `ico`、Linux PNG、iOS 与 Android 图标，并给浏览器模式补上 favicon。
- 保留 v0.1.4 的原生透明标题栏：窗口激活后仍可从顶部原生标题栏直接拖动。

## 功能

包含 v0.1.2 / v0.1.3 / v0.1.4 的全部能力：

- Undo / Redo、查找替换（`⌘F`）
- 本地图片粘贴/拖放、Markdown 图片导出、Word 内嵌图片
- 选中字数、空状态文案
- 本地 SQLite 存储，无账号、无云同步、无遥测

## 安装

1. 下载 `PlainEssay_0.1.5_universal.dmg`（Apple Silicon + Intel，macOS 12+）。
2. 打开 DMG，将 PlainEssay 拖入 `/Applications`。
3. 右键应用 → 打开 → 打开。未签名/未公证，首次启动需要手动放行。
4. 若提示已损坏，执行：

```sh
xattr -dr com.apple.quarantine /Applications/PlainEssay.app
```

## 数据位置

```text
~/Library/Application Support/com.phanstal.plainessay/plainessay.db
```

删除应用不会删除数据；如需清空，请手动删除上述目录。

## 已知限制

- 无代码签名与公证，无自动更新
- 仅段落 + 粗体/斜体/下划线 + 本地图片；不支持标题层级、列表、链接、图片缩放/裁切
- 单张图片上限 12 MB；WebP 可显示和导出 Markdown，但 Word 导出会跳过
- 查找替换按单个文本节点匹配，跨格式边界的短语不视为一个匹配
- 删除不可撤销
- 窗口关闭时最多丢失最后约 600 ms 的输入（返回或 `⌘S` 会立即保存）
- 无数据库加密、无同步、仅英文界面
