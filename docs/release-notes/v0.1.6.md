# Plain v0.1.6

补齐 Figma Make Version 12 的 Word 导出设置，并让应用名称统一为 **Plain**。

## 命名

- 应用名、窗口标题、macOS 菜单、安装包与发布标题全部改为 `Plain`。
- 左上角字标保持 `Plain`，与 Version 12 一致。
- 内部 Bundle ID（`com.phanstal.plainessay`）、数据库目录与 `plainessay.db` 文件名保持不变，升级后原有文章仍可打开。

## Word 导出

`Export .docx` 现在先打开 `Export document` 设置弹窗，布局与 Figma Version 12 对齐：

- **Typeface**：Times New Roman · 12 pt（默认）或 Arial · 12 pt。
- **Line spacing**：Double-spaced（默认）或 Single-spaced。
- **Paper size**：US Letter · 8.5 × 11 in（默认）或 A4 · 210 × 297 mm。
- 摘要固定显示 `1-inch margins · 0.5-inch first-line indent · black text`。
- 每个正文段落首行缩进 0.5 英寸；标题居中和图片段落不缩进。
- 导出时把正文与标题中的直双引号、直单引号、撇号转换为弯引号，例如 `"it's"` → `“it’s”`，Markdown 导出同样处理。
- 保留粗体、斜体、下划线、多段落、嵌入图片与标题的 Word 元数据。

## 其它

- Markdown 导出也会清洗直引号，并保留 `**`、`*`、`<u>` 与本地图片。
- 版本号升至 `0.1.6`；图标与 v0.1.5 相同。

## 安装

1. 下载 `Plain_0.1.6_universal.dmg`（Apple Silicon + Intel，macOS 12+）。
2. 打开 DMG，将 `Plain` 拖入 `/Applications`。
3. 右键应用 → 打开 → 打开。未签名/未公证，首次启动需要手动放行。
4. 若提示已损坏，执行：

```sh
xattr -dr com.apple.quarantine /Applications/Plain.app
```

## 数据位置

```text
~/Library/Application Support/com.phanstal.plainessay/plainessay.db
```

删除应用不会删除数据；如需清空，请手动删除上述目录。

## 已知限制

- 无代码签名与公证，无自动更新
- 仅段落 + 粗体/斜体/下划线 + 本地图片；不支持标题层级、列表、链接、图片缩放/裁切
- 单张图片上限 12 MB；WebP 可显示和导出 Markdown，但 Word 导出会跳过
- 查找替换按单个文本节点匹配，跨格式边界的短语不视为一个匹配
- 删除不可撤销
- 窗口关闭时最多丢失最后约 600 ms 的输入（返回或 `⌘S` 会立即保存）
- 无数据库加密、无同步、仅英文界面
