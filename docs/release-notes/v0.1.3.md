# PlainEssay v0.1.3

修复 macOS 窗口化模式下标题栏几乎无法拖动窗口的问题。

## 修复

- 窗口拖动区域改为 Tauri 的 `data-tauri-drag-region="deep"`。此前只给 header 加了裸属性，Tauri 只识别“直接点中 header 本身”的拖动；编辑页的字标、保存状态和右侧操作区几乎铺满整个标题栏，点击这些子元素不会触发拖动，所以表现为“基本拖不动”。
- 删除 `-webkit-app-region` CSS。该属性由 WebView 自行处理，和 Tauri 原生拖动逻辑叠在一起容易产生冲突；现在统一交给 Tauri 原生拖动区域。
- 按钮、输入框、可编辑区域和查找条仍保持可点击；双击标题栏空白处仍可触发窗口最大化/还原。

## 包含 v0.1.2 的编辑体验

- Undo / Redo、查找替换（`⌘F`）、本地图片粘贴/拖放、选中字数、空状态新文案
- Markdown 图片导出、Word 内嵌图片
- 本地 SQLite 存储，无账号、无云同步、无遥测

## 安装

1. 下载 `PlainEssay_0.1.3_universal.dmg`（Apple Silicon + Intel，macOS 12+）。
2. 打开 DMG，将 PlainEssay 拖入 `/Applications`。
3. 右键应用 → 打开 → 打开。未签名/未公证，首次启动需要手动放行。
4. 若提示已损坏，执行：

```sh
xattr -dr com.apple.quarantine /Applications/PlainEssay.app
```

## 数据位置

```text
~/Library/Application Support/com.phanstal.plainessay/plainessay.db
```

删除应用不会删除数据；如需清空，请手动删除上述目录。

## 已知限制

- 无代码签名与公证，无自动更新
- 仅段落 + 粗体/斜体/下划线 + 本地图片；不支持标题层级、列表、链接、图片缩放/裁切
- 单张图片上限 12 MB；WebP 可显示和导出 Markdown，但 Word 导出会跳过
- 查找替换按单个文本节点匹配，跨格式边界的短语不视为一个匹配
- 删除不可撤销
- 窗口关闭时最多丢失最后约 600 ms 的输入（返回或 `⌘S` 会立即保存）
- 无数据库加密、无同步、仅英文界面
