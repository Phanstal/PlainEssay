# PlainEssay v0.1.2

对齐最新 Figma Make 原型（Version 11）的编辑体验，仍然完全本地、无账号、无网络。

## 新增

- **撤销 / 重做**：浮动工具条新增 Undo / Redo，与 `⌘Z` / `⇧⌘Z` 行为一致，无历史时置灰。
- **查找与替换**：`⌘F` 或 `Edit → Find…` 打开查找条；支持上一个/下一个、Replace、Replace all、匹配计数与 Esc 关闭。
- **本地图片**：从剪贴板粘贴或拖入 PNG / JPEG / GIF / WebP，图片以内嵌 data URL 保存到本地数据库，不上传；拖动时显示虚线投放区域。
- **选中字数**：选中文本时右上角显示 `${n} selected`，取消选择后恢复总字数。
- **空状态文案**：改为 `Start a new essay` / `A quiet page is ready when you are.`。
- **导出**：Markdown 把本地图片导出为图片语法；Word 将 PNG/JPEG/GIF 作为内嵌媒体写入，按比例限制在正文宽度内。
- **窗口拖动**：顶部空白区域可拖动窗口，按钮、输入框和查找条不触发拖动。

## 安装

1. 下载 `PlainEssay_0.1.2_universal.dmg`（Apple Silicon + Intel，macOS 12+）。
2. 打开 DMG，将 PlainEssay 拖入 `/Applications`。
3. 右键应用 → 打开 → 打开。未签名/未公证，首次启动需要手动放行。
4. 若提示已损坏，执行：

```sh
xattr -dr com.apple.quarantine /Applications/PlainEssay.app
```

## 数据位置

```text
~/Library/Application Support/com.phanstal.plainessay/plainessay.db
```

删除应用不会删除数据；如需清空，请手动删除上述目录。图片以 base64 存在数据库内，含图片的文档会让数据库变大。

## 已知限制

- 无代码签名与公证，无自动更新
- 仅段落 + 粗体/斜体/下划线 + 本地图片；不支持标题层级、列表、链接、图片缩放/裁切
- 单张图片上限 12 MB；WebP 可显示和导出 Markdown，但 Word 导出会跳过
- 查找替换按单个文本节点匹配，跨格式边界的短语不视为一个匹配
- 删除不可撤销
- 窗口关闭时最多丢失最后约 600 ms 的输入（返回或 `⌘S` 会立即保存）
- 无数据库加密、无同步、仅英文界面
